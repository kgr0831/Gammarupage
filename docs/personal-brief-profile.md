# 개인 데일리 브리핑 — 조사 대상

이 보고서는 한 사람의 공모전·채용 탐색을 돕는다. 동아리 운영자금 보고서가 아니다.

## 확정한 관심사

- 공모전: 개발·AI·IT 전반. 개인 또는 개인이 팀을 구성해 참여할 수 있는 공모전·해커톤·경진대회.
- 채용: 개발·AI·IT 전반. 공식 채용 페이지의 실제 개별 공고.
- 미국 주식·ETF·트레이딩: 2026-10-06 사용자 요청으로 이번 개인 보고서에서 제외.
- 형식: 한국어 일일 HTML. 기존 색상·폰트, 모바일 가독성, 분야별 요약과 클릭형 진행 기록.
- 전달: 소유자만 열람하며 본인 Discord DM으로 요약·링크를 받는다.

## 아직 확인되지 않은 개인 조건

재학·졸업 여부, 학년, 나이, 경력, 기술 스택, 포트폴리오, 희망 근무 지역과 형태, 팀 구성 가능 여부는 미확정이다.
겜마루 소개에서 개인의 학적·경력·실적을 추정하지 않는다. 지원 가능성을 확정하지 말고 공고 자격과 부족한 정보를 분리해서 표시한다.
필요한 개인 정보는 소유자가 추가로 알려준 내용만 사용하며 공개 저장소·보고서 요약·로그에 민감한 정보를 넣지 않는다.
소유자가 `/reports/profile`에서 저장한 조건은 이 문서 아래에 비공개로 붙는다. 저장된 구체 조건이 있으면
위의 '미확정' 기본값보다 우선하며, 빈 값은 계속 미정이다. 공개 저장소의 이 파일에 개인 조건을 직접 기록하지 않는다.

## 선택 기준

- 공모전·채용은 공식 접수 여부, 마감 시간대, 자격, 비용·보상, 제출물, 근무 조건을 확인한다.
- 지역·학적·경력 제한이 확인되지 않으면 '지원 자격 확인 필요'로 표시한다. 결과 수를 채우기 위해 부적격 공고를 추천하지 않는다.
- 개인 참가와 팀 참가를 구분하고, 팀 구성 가능 여부를 추정하지 않는다.
- 같은 공고는 기존 ID를 유지하고, 신규·변경·진행 중 정보를 구분한다.
- 완료·안함은 중요한 새 변화가 있을 때만 다시 소개한다. 보류 사유와 메모를 다음 조사에 반영한다.
- 기존 동아리 지원 항목(legacyIds)은 저장 이력으로만 참고하고 개인 보고서에 반복 추천하지 않는다.

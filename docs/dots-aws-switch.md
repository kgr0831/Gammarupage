# 기존 dots 예약의 AWS 주소 변경

아래 블록을 기존 dots 대화에 전달한다. 예약 시간은 유지하고 사이트 주소와 로그인만 갱신한다.
두 공간의 업로드 키는 이전과 동일하며 서로 다르다. 키를 이 문서나 채팅에 붙이지 않는다.

```text
겜마루와 공모전·채용 보고서 사이트를 AWS로 이전했어.
기존 두 예약의 주소를 아래 주소로 변경하고, 한국시간 08시 조사·09시 보고와 활성 상태는 유지해줘.
새 예약을 중복 생성하지 마. 이번 요청만으로 오늘 보고서를 재발행하거나 알림을 다시 보내지 마.

AWS는 새 저장소로 시작했어. 이전 Vercel의 stateVersion·회원·상태·메모가 옮겨졌다고 가정하지 마.
사이트의 최신 지침·자료와 상태를 조사 시작 시, 발행 직전에 각각 다시 읽어줘.
겜마루는 동아리가 직접 받을 운영비·후원 물품·장비·공간·단체 자원만 조사해줘.
개인은 개발·AI·IT 공모전과 채용을 조사하고 트레이딩은 제외해줘.
확인하지 못한 개인 조건이나 자격을 추정하지 말고 비공개 프로필·메모를 공개 보고서에 싣지 마.
오늘 발행 여부와 최신 stateVersion을 확인하고, 수정 요청 없는 중복 발행을 하지 마.
최근 7개 한국 날짜의 HTML만 보관되므로 과거 항목 중복 판단은 known과 진행 기록도 확인해줘.
```

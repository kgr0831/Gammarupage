# dots 개인 일일 조사·HTML 보고 운영 지침

현재 목적은 **개발·AI·IT 공모전 / 개발·AI·IT 채용공고**다.
미국 주식·ETF·트레이딩은 2026-10-06 사용자 요청으로 이번 작업에서 제외한다.
겜마루와 같은 도메인의 /personal에서 운영하는 비공개 개인 공간이다. 기존 동아리 작업과 예약을 유지하고 개인 작업을 별도로 만든다.

## 실행 환경과 권한

- 개인 공간: {{REPORTS_BASE_URL}}
- 로그인: {{REPORTS_BASE_URL}}/login/publisher
- HTML 자료 보기: {{REPORTS_BASE_URL}}/upload?guide=1
- 업로드: {{REPORTS_BASE_URL}}/upload
- 자료 보기에 운영 지침, 조사 대상 정보, Design.md, 전체 진행 기록 JSON이 포함돼 있다.
- 텍스트·JSON 주소가 ERR_BLOCKED_BY_CLIENT로 막히면 HTML 자료 보기의 각 섹션을 읽는다.
- 소유자 PC와 별개인 dots 클라우드에서 조사·파일 생성·업로드를 수행한다.
- 업로드 키는 비공개 로그인에서 입력한다. 관리자·Discord·저장소 키를 dot에게 주지 않는다.
- 업로드 세션은 최대 30일이다. 만료되면 비공개 재로그인이 필요하다.
- 보고서 작성·업로드와 사이트를 통한 **소유자가 연결한 Discord 계정의 DM** 알림은 맡긴 범위에 포함된다.
- 수신 계정은 소유자가 개인 ID/PW 로그인 후 연결한다. dot은 계정 연결이나 수신 대상을 변경하지 않는다.
  미연결·DM 꺼짐·전송 실패이면 그 상태를 보고한다. 서버 채널이나 다른 계정으로 대체 발송하지 않는다.
- 지원서 제출, 참가 신청, 문의 발송, 계약·결제·매매 주문은 실행하지 않는다.

## dot에게 줄 지시문

```text
동아리 작업과 별도로 개인 데일리 브리핑 작업을 만들어줘.
동아리 예약을 변경하지 마. 같은 개인용 예약이 이미 있을 때만 그 개인 예약을 갱신해줘.
내 PC가 꺼져 있어도 가능한 너의 클라우드 컴퓨터에서 실행해줘.

매일 오전 9시, Asia/Seoul 시간대에 아래 작업을 실행해줘.
처음에는 지금 한 번 실제 발행을 확인한 뒤 일정을 저장하고, 일정 이름·시스템이 반환한 다음 실행 시각을 알려줘.
예약 생성·갱신은 최초 설정 요청에서만 수행하고, 정기 실행에는 아래 1~9번의 조사·발행 절차를 저장해줘.
완료 보고는 이 ChatGPT 대화에, 새 보고서 요약·링크는 사이트를 통한 내 Discord DM에 전달해줘.

1. {{REPORTS_BASE_URL}}/upload?guide=1 을 실제로 열어줘.
   로그인 화면이면 비공개 로그인 인계를 요청해줘.
   이 페이지의 운영 지침, 조사 대상 정보, Design.md, research-state-json 전체를 읽어줘.
   조사 대상 정보 아래에 소유자가 비공개로 저장한 학적·기술·프로젝트·동아리 활동·선호·지역·참가 조건 등이 있으면 그 조건을 적용해줘.
   직접 제공한 경험과 현재 기획 중인 프로젝트를 구분하고, 미완성 프로젝트를 경력이나 수상 실적으로 바꾸지 마.
   해당 내용을 DM 요약에 그대로 복사하지 마. 빈 조건은 미정으로 두고 자격을 추정하지 마.
   {{REPORTS_BASE_URL}}/context, {{REPORTS_BASE_URL}}/design, {{REPORTS_BASE_URL}}/research-state에서도 같은 자료를 얻을 수 있어.
   HTML 자료 보기에도 접근할 수 없으면 추측해서 진행하지 말고 막힌 단계를 알려줘.

2. 한국시간 오늘 날짜와 stateVersion, known, carryForwardIds, legacyIds,
   excludedUnlessChangedIds, previousReports를 확인해줘.
   정기 실행에서 오늘 개인 보고서가 이미 등록돼 있으면 중복 발행하지 말고 남은 알림만 확인해줘.
   단, 사용자가 변경 사항 반영·정정·재발행을 명시적으로 요청했다면 최신 지침·개인 조건·진행 기록을
   다시 읽어 같은 날짜의 수정본을 작성해줘. 단순 정기 실행이나 전송 재시도는 재발행 사유가 아니야.
   동아리 보고서가 보이면 다른 서비스에 접속한 것이므로 개인 사이트 주소를 다시 확인해줘.
   이전 지원 공고는 같은 ID·공식 원문 URL을 유지하고 날짜를 붙여 새 항목처럼 만들지 마.
   legacyIds와 category=support는 과거 동아리 정보이므로 개인 추천에서 제외해줘.
   보류·진행 중 항목은 저장된 메모를 읽고 새 변화가 있을 때 간단히 갱신해줘.
   완료·안함은 원칙적으로 제외하고 중요한 새 변화가 있을 때만 changeNote를 적어줘.

3. 오늘의 웹 조사로 다음 두 분야를 각각 확인해줘.
   A. 공모전: 개발·AI·IT 공모전, 해커톤, 경진대회. 개인/팀 참가, 자격, 주최자,
      접수 상태, 마감 시간대, 비용, 상금·혜택, 제출물을 공식 공고로 확인해줘.
   B. 채용: 개발·AI·IT 기업의 공식 개별 공고. 직무, 경력·기술 요건, 고용형태,
      근무지·원격 여부, 접수 상태, 마감, 명시된 보상을 확인해줘.
      마감된 채용을 현재 지원 가능하다고 쓰지 마. 비공식 재게시만으로 접수를 확정하지 마.

   자격이 불분명하면 지원 자격 확인 필요로 분류하고 적합하다고 단정하지 마.

4. 새 정보는 공모전 최대 3개, 채용 최대 3개를 우선하고,
   이어서 검토할 항목을 포함해 총 20개 이내로 작성해줘. 개수를 채우려고 약한 자료를 넣지 마.
   각 분야에 신규/변경/이어서 검토 표시, 출처, 확인 시각과 추천하는 다음 행동을 담아줘.

   검색·접근 장애는 확인 실패로 명시하고 정상적인 결과 없음으로 바꾸지 마.

5. 최신 Design.md에 맞는 한국어 HTML 파일을 만들어줘.
   첫 화면에 오늘 결론, 분야별 요약, 오늘 할 일 최대 3개를 보여줘.
   공모전 / 채용공고 두 구역을 분리하고 본문은 한 열로 배치해줘.
   모바일 16px 이상, 데스크톱 17~18px, 줄 간격 1.8 이상을 지켜줘.
   긴 근거는 details로 접되 핵심 자격·마감·비용·위험·불확실성은 바로 보이게 해줘.
   UTF-8, 2MB 이하, html/body와 문서 내 CSS를 포함하고 .html 파일로 저장해줘.
   실행 JavaScript, 폼, 추적 코드, 비밀값, 불필요한 개인정보를 넣지 마.

6. script[type=application/json]#gammaru-opportunities 데이터 블록을 넣어줘.

   내용과 금액·마감·위험을 숨기지 않으면서 benefit은 80자 안팎, nextAction은 60자 안팎으로 요약해줘.

7. {{REPORTS_BASE_URL}}/upload에서 오늘 날짜, 제목, 300자 이내의 2~3문장 요약, HTML 파일을 입력해줘.
   파일 선택이 어려우면 '파일 대신 HTML 내용 붙여넣기'에 전체 문서를 입력해줘. 두 방식 중 하나만 사용해줘.
```

## 독립 운영

최초 연결을 마친 뒤 예약의 이름·활성 상태·Asia/Seoul 오전 9시 설정을 실제 저장 결과로 확인한다.
다음 실행 시각이 null이거나 조회되지 않으면 미확인으로 보고하며 계산값을 시스템 확인값처럼 말하지 않는다.

- 개인 보고서·진행 기록·세션은 동아리 서비스와 별도 저장한다. 관리자와 승인된 소유자 계정만 열람·상태 변경이 가능하다.
- 기존 다른 구독자의 승인은 개인 보고서 접근이나 DM 수신 권한을 주지 않는다.
- category와 audience로 개인 항목을 구분한다. 이전 동아리 항목은 신규 개인 추천에 포함하지 않는다.
- 개인 사이트의 별도 로그인·업로드 키와 Private Blob을 사용한다. 기존 Dishost 동아리 알림 봇의 연결은 바꾸지 않는다.
- 이 저장소에서 dots 예약을 자동 등록하지 않는다. 첫 발행과 Scheduled의 저장 상태를 따로 확인한다.
- 팩트챗 자동 대체, 지원서·메일 실행, 자동 매매는 구현 범위에 포함되지 않는다.

공식 안내: [예약 확인](https://learn.chatgpt.com/docs/dots/tasks-and-memory), [클라우드 로그인](https://learn.chatgpt.com/docs/dots/computers-and-apps).

    겜마루 소개

    1995년 설립된 숭실대학교 게임 제작 중앙동아리. 기획·프로그래밍·아트·사운드 분야의 학생들이 팀을 구성해 게임 제작.

    숭실대학교 학생 대상. 전공·학년과 관계없이 참여 가능.

    제작 분야

    규칙·레벨·밸런스 설계

    핵심 플레이 구조와 진행 방식 설계. 기획서 작성과 팀의 제작 방향 정리.

    게임 시스템 구현

    Unity, Unreal 등으로 입력·규칙·피드백 구현. 빌드 제작과 반복 개선.

    그래픽·애니메이션·UI 제작

    2D·3D 캐릭터와 배경, 애니메이션, 게임 화면의 인터페이스 제작.

    음악·효과음 제작

    배경음악과 효과음 제작. 장면과 플레이 동작에 맞춰 게임에 적용.

    활동

    여름·겨울 공모전

    방학 중 팀·개인 게임 제작. 기획, 중간 진행, 최종 빌드 발표.

    게임잼

    새 주제와 팀으로 72시간 안에 플레이 가능한 게임 제작.

    보드게임잼

    제한된 재료와 시간 안에 규칙을 설계하고 직접 플레이.

    스터디·아무말 발표회

    Unity, Unreal, Ren'Py, 아트, 게임 수학, 기획 학습과 발표.

    OBYB·업계 교류

    선배·현업자 피드백, 진로 멘토링, 다른 대학 동아리와의 교류.

# Hero showreel assets

The site looks for one finished showreel at either:

- `public/media/hero-reel.webm`
- `public/media/hero-reel.mp4`

The reel is silent and plays once. When playback ends, the page replaces it with `public/brand/hero-end-frame.*`. Current edit:

1. Six to eight approved, face-free gameplay clips.
2. Use a clear middle section from each game for 3–4 seconds.
3. Finish with a four-game mosaic.
4. Let the page transition to the GAMMARU end frame.
5. Keep the highest practical source quality; the site does not request a low-quality variant.

Until a reel exists, the hero uses the high-resolution branded end frame automatically.
